# Ghost Browser

একটি প্রাইভেসি ব্রাউজার: সাইট ফোনের কোন তথ্য চাইছে তা পপআপে দেখায়, আপনি আসল / নকল (এডিট করা) / ব্লক বেছে নিতে পারেন।

## APK বানানো (কম্পিউটার ছাড়া, ফোন থেকে)
1. github.com-এ একটি নতুন repository খুলুন।
2. এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডারসহ) আপলোড করুন।
3. repository-র **Actions** ট্যাবে যান → **Build APK** → লাল/সবুজ রান খুলুন।
4. শেষে নিচে **Artifacts** থেকে `GhostBrowser-apk` ডাউনলোড করুন, ZIP খুলে `app-debug.apk` ইনস্টল করুন।
   (প্রথমবার "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হবে।)

## ব্যবহার
- ভাসমান **G** আইকনে ট্যাপ → প্যানেল (প্রোফাইল / নিয়ম / লগ)।
- আইকনে ৭০০ms চেপে ধরে রাখলে হাইড হয়; অ্যাপ বের হয়ে আবার ঢুকলে ফিরে আসে।
- ড্র্যাগ করে আইকন সরানো যায়।
- IP লুকাতে আলাদা VPN চালু রাখুন।
